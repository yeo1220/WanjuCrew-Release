내 Mac에 로그인된 AI를 설계·구현·검토·검증 역할로 연결하고, 실행 전에 사람이 승인하는 작업 지휘소입니다.

시작하기

  1. Mac 지휘소와 CLI를 배포 페이지에서 받습니다. macOS 15 이상이 필요합니다.
  2. 본인의 Codex 계정으로 로그인하고 작업할 폴더를 선택합니다. AI 서비스의 이용료와 이용 조건은 별도입니다.
  3. 작업을 요청하고, 사용할 모델과 변경 범위를 확인한 뒤 승인합니다.
  4. 동반 앱의 연결 화면에 Mac 주소와 페어링 토큰을 입력하면 진행 확인과 승인이 가능합니다. iPhone/iPad는 iOS 18 이상입니다.

CLI: wanju serve, wanju status, wanju approvals, wanju cancel 작업UUID

무료와 Pro

기본 AI 작업, 모델 연결, 승인·거절·중단과 실행 기록은 무료입니다. Pro는 SSH 원격 명령과 개발자용 자체 개선을 제공합니다. 자체 개선에는 완주단 소스, Xcode, XcodeGen이 필요하며 실행 앱을 자동 교체하지 않습니다.

한국 기준: 월 1,900원 / 연 9,900원 / 영구 구매 19,900원. 실제 구매 가능 여부와 최종 금액은 App Store 구매 화면에서 확인하세요.

구독은 해당 기간마다 자동 갱신됩니다. 영구 구매는 자동 결제 없이, 구매 후 1년 동안 출시된 Mac Pro 버전을 계속 사용할 수 있습니다. 이후 새 버전 업데이트는 선택 사항입니다. 미래의 모든 업데이트를 포함하는 상품은 아닙니다.

동반 앱의 Pro 화면에서 구매·복원하고 Mac에 동기화합니다. 영구 구매를 해도 기존 구독은 자동 해지되지 않습니다. Apple 구독 관리에서 별도로 해지하세요.

연결과 문제 해결

Mac 지휘소는 한 번에 하나만 실행하세요. 같은 Mac에서는 http://127.0.0.1:8787로 연결할 수 있습니다. 다른 기기에서는 신뢰할 수 있는 사설망이나 VPN을 사용하세요. 공용 인터넷에 포트를 직접 노출하지 마세요. 페어링 토큰은 기기 제어 권한이므로 다른 사람에게 공개하지 마세요.

AI의 완료 메시지만으로 정확성을 보장하지 않습니다. 실행 기록과 변경 파일을 확인하세요. 중단은 이미 수행한 파일 변경이나 원격 명령을 되돌리지 않습니다. 원격 프로세스가 계속 실행 중인지 별도 확인이 필요할 수 있습니다.

구매가 반영되지 않으면 동반 앱에서 구매 복원 후 Mac에 구매 동기화를 누르세요. 환불은 Apple 문제 신고에서 요청할 수 있습니다.
